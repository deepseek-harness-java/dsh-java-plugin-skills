# 案例储备库 — 一句话智能体应用 Prompt

用途：用户没有明确应用诉求时，从这里抽 **3~5 个跨分类案例**（完整话术，非标题）展示给用户；用户选定（或原样粘贴）后，按该话术直接走 SKILL.md 工作流开发、启动、部署。每个 prompt 均可独立指导开发和运行，无需补充信息（端口、数据、技术栈等按 SKILL.md 默认项处理）。

## 使用规则

1. **用户问"能做什么/举个例子"** → 按下面分类轮换抽 3~5 个（跨大分类），原话术展示，并说明"选定任意一个即可一句话完成开发+部署启动运行"
2. **用户粘贴/改写其中一个** → 该 prompt 即为需求输入，直接进入阶段 0（唯一要确认的只有"新开发 or 对接已有应用"）
3. **用户领域不在库中** → 参照同分类句式即时生成一个同结构 prompt（业务实体 + 5 个 AI 工具 + 前端 + AI 助手 + 交付），同样一句话可执行
4. 展示时附上对应"AI 能力亮点"，这个案例做出来是什么样

## 商城/零售

**P1 虚拟数码商城**：`开发一个 PC 端虚拟数码商城，内置 12 件商品和演示用户，支持商品搜索、购物车、下单、模拟支付和订单查询；页面右上角有 AI 购物助手，能理解自然语言推荐商品、查订单、查物流，接入 DSH 插件后启动给我地址。`

AI 亮点：AI 助手可跨"商品/订单/物流"多工具联动回答（对比推荐、订单追踪一句话完成）。

**P2 生鲜团购平台**：`开发一个生鲜社区团购应用，含今日团购商品列表、拼团进度、自提点选择和订单管理，预置 3 个社区自提点数据；AI 助手可以推荐今日特价菜、查询最近的拼团和自提点，插件接入 DSH 运行起来。`

## 金融/信贷

## Prompt 结构公式（用于生成库外案例）

```
开发一个 PC 端 <领域应用>，
含 <核心功能 3~4 项>，预置 <演示数据规模>；
AI <角色名>助手能 <3 个跨工具的智能能力>，
<以插件接入 DSH 运行 / 启动运行给我地址>。
```

生成时保持：**业务实体明确**（便于列实体→设计工具）、**AI 能力必须跨工具联动**（体现智能体价值，而非单查询）、**演示数据有规模**（页面不空）。每个案例默认交付：DSH 8090 + 应用地址 + 插件工具清单 + 使用说明。
